# soco cafe HP

## 公開方法(GitHub Pages / URLを知っている人だけに公開)

1. GitHubで新しいリポジトリを作成(例: `soco-cafe`)。**Private** を選択する(ソースコードや写真をGitHub上で非公開にするため)
2. このフォルダの中身(`index.html` / `robots.txt` / `images` フォルダ)をリポジトリ直下にアップロード
3. リポジトリの Settings → Pages を開く
4. 「Branch」を `main` / `root` に設定して Save
5. 数分後、`https://(ユーザー名).github.io/soco-cafe/` で公開される

※ リポジトリをPrivateにしても、GitHub Pagesで公開されたサイト自体は「URLを知っていれば誰でも見られる」状態になります(ログイン不要)。これは仕様上の制限で、検索エンジンには載らないようにしていますが、パスワード認証ではありません。URLはInstagramのプロフィールなど、教えたい相手にだけ共有してください。

## 検索エンジン対策について

`index.html` に `noindex` のmetaタグ、ルート直下に `robots.txt` を設置済みです。これによりGoogle等の検索結果には基本的に表示されなくなりますが、反映まで数週間かかることがあります(元々公開していなければ、最初から登録されないのですぐ効果があります)。

## 写真を差し替えたいとき

`images` フォルダの中の `hero.jpg`(トップの大きい写真)と `gallery-1.jpg`(ギャラリーの写真)を、
同じファイル名で新しい写真に上書きすればOKです。ファイル名を変える場合は `index.html` 内の
`src="images/○○.jpg"` の部分も合わせて書き換えてください。

## メニューや住所を変えたいとき

`index.html` を開いて、該当する文字を直接書き換えるだけで反映されます(再デプロイ不要、
GitHubにpushし直せば自動で更新されます)。
